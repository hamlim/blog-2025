If you ever find youself wondering:

> What PRs did I open in the month of August this year?

You can use the `created:` filter within the PR search view (note this isn't limited to only PRs, I think it should work in any filter search across GitHub!)

```txt
created:YYYY-MM-DD..YYYY-MM-DD
```

So for example:

```txt
author:hamlim created:2025-09-01..2025-09-30
```

Should show the PRs/Issues that I created in the month of September 2025!
