If you're using Codex (or the new ChatGPT for Work) features within the ChatGPT app, I recommend spinning up a dedicated chat thread called your [Chief of Staff](https://jxnl.co/writing/2026/05/10/codex-maxxing/). This thread can now become your go-to thread for coordinating your work, keeping you up to date on new emails/events/etc, and generally acting as a first touch point for any work you want to do.

Codex/ChatGPT for Work also has the ability for threads to spin up other threads for you, so I often start from my Chief of Staff thread which is pinned in the app, and tell it that I want to work on something and have it spin up a dedicated thread for that work for me.
